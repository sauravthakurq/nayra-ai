#  Nayra AI

India's Sovereign Voice AI Platform built with modern glassmorphism UI and support for both premium AI voices and free native browser voices.

![Nayra AI](assets/preview.png)

## ✨ Features

- 🇮🇳 Indian Language Support
- 🎤 Sarvam AI Integration (Bulbul v3)
- 🆓 Free Native Browser TTS
- ⚡ Modern Glassmorphism Interface
- 🎚️ Playback Speed Controls
- 🔐 Secure API Key Storage
- 📥 Audio Download Support
- 📱 Fully Responsive Design

## Supported Languages

- Hindi
- English (India)
- Bengali
- Tamil
- Telugu
- Marathi
- Gujarati
- Kannada
- Malayalam
- Punjabi

## Tech Stack

- HTML5
- TailwindCSS
- JavaScript
- Font Awesome
- Sarvam AI API
